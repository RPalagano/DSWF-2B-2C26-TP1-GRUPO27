## 🕹️ Sobre el proyecto

La página funciona como una especie de **máquina arcade virtual**, donde el usuario puede recorrer diferentes secciones y conocer a los integrantes del equipo.

Desde la portada se puede:

* 🎮 Conocer al equipo.
* 🧑‍💻 Seleccionar los diferentes personajes/integrantes.
* 👤 Acceder a los perfiles individuales.
* 📖 Consultar la bitácora del proyecto.
* 🪙 Interactuar con elementos inspirados en una máquina arcade.
* 🔊 Activar o desactivar el sonido.
* 📺 Activar o desactivar el efecto de líneas CRT (*scanlines*).

La portada incluye una sección de selección de personajes y una estación interactiva que permite probar diferentes acciones de la interfaz.

## 🎨 Diseño y experiencia de usuario

La identidad visual del proyecto está basada en el concepto de una **máquina arcade retro**.

Algunos elementos utilizados son:

* Pantallas estilo CRT.
* Tipografías y elementos visuales inspirados en videojuegos.
* Bordes y sombras luminosas.
* Colores neón.
* Botones interactivos.
* Sistema de selección de personajes.
* Elementos de HUD (*Heads-Up Display*).
* Animaciones y efectos visuales.

La página principal utiliza además una estructura responsive para adaptar la experiencia a diferentes tamaños de pantalla.

## 🎮 Experiencia interactiva

Uno de los objetivos del proyecto es que la página no sea solamente informativa, sino que tenga elementos con los que el usuario pueda interactuar.

Entre ellos se encuentran:

```text
🪙 INSERTAR MONEDA
🔊 AUDIO ON/OFF
📺 SCANLINES ON/OFF
🎮 PRUEBA LA CONSOLA
👾 SELECCIÓN DE PERSONAJES
```

La interfaz incluye un contador de créditos y una sección denominada **"Prueba la consola"**, diseñada para incorporar interacciones mediante JavaScript.

## 🚀 Cómo ejecutar el proyecto

No es necesario instalar dependencias para visualizar la página.

### Opción 1 — Abrir directamente

Descargar o clonar el repositorio y abrir:

```text
index.html
```

en un navegador web.

### Opción 2 — Visual Studio Code

1. Clonar el repositorio.
2. Abrir la carpeta en **Visual Studio Code**.
3. Abrir `index.html`.
4. Ejecutar el proyecto utilizando **Live Server**.
