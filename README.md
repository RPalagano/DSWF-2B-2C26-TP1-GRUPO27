# Tu Máquina Retro Dev

> **Un equipo, una partida.**

Sitio web del grupo 27 para presentar al equipo y su proceso de trabajo con una estética inspirada en las máquinas arcade y los videojuegos retro.

## Qué incluye

- Portada con selección de personajes y enlaces a los perfiles.
- Cuatro páginas de perfil para conocer a cada integrante.
- Bitácora con entradas del proceso de desarrollo y filtros por categoría.
- Interfaz adaptable a distintos tamaños de pantalla, con controles de audio y scanlines.
- Interacción de consola en la portada y actividades en algunos perfiles.

## Cómo ejecutar

No hace falta instalar dependencias. Cloná el repositorio y abrí `index.html` en un navegador. También podés abrir la carpeta en Visual Studio Code y usar Live Server para servir el sitio localmente.
